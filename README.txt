# VoidPhantoms — Premium 3D Coding Club Website

## Included
- `index.html` — website structure
- `styles.css` — premium glassmorphism / neon styling
- `script.js` — 3D tilt, magnetic hover, liquid cursor glow, particles, scroll reveals and parallax
- `assets/city-bg-1.jpg` and `assets/city-bg-2.jpg` — your supplied backgrounds

## Run locally
Open `index.html` in a browser.

For the best experience, use a small local server:
- VS Code + Live Server, or
- Python: `python -m http.server`

## Customize
1. Replace `voidphantoms@example.com` in `index.html` with the club's real email.
2. Replace the IG/GH/DC footer links with your actual social links.
3. Change text in `index.html` to match your club.
4. Upload the whole folder to GitHub Pages.

No build step is required.
